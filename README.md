# 🚀 Installation & Setup


## 1. Clone Repository

```bash
git clone https://github.com/ananyadevanga139-jpg/AI-Task-Management-System.git
Frontend Setup
cd frontend

npm install

npm run dev

Frontend runs on:

http://localhost:5173
Backend Setup
cd backend

npm install

npm run dev

Backend runs on:

http://localhost:5000
🔐 Environment Variables

Create .env file inside backend:

PORT=5000

DATABASE_URL=your_postgresql_database_url

JWT_SECRET=your_secret_key
